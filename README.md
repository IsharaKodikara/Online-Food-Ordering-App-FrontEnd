Online Food Ordering System - Frontend

A React TypeScript frontend application for the Online Food Ordering System.
This frontend allows users to browse foods, manage cart items, and place orders through a responsive web interface.

🚀 Technologies Used
React
TypeScript
Axios
Bootstrap 5
React Router DOM
HTML5
CSS3
📂 Project Structure
src
├── components
├── pages
├── services
├── models
├── routes
├── App.tsx
└── main.tsx
⚙️ Features
User Login & Registration
Food Browsing
Category Filtering
Add To Cart
Remove Cart Items
View Orders
Responsive UI
REST API Integration
🛠️ Installation & Setup
1. Clone Repository
git clone https://github.com/YOUR_USERNAME/OnlineFoodOrderingSystem-Frontend.git
2. Open Project

Open the frontend project using:

VS Code
IntelliJ IDEA
3. Install Dependencies
npm install
4. Configure Backend URL

Make sure backend server is running on:

http://localhost:8080
5. Run Frontend Application
npm start

Application will run on:

http://localhost:3000
